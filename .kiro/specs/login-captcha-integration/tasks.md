# 实现计划: 登录验证码集成

## 概述

本实现计划将登录验证码集成功能分解为一系列增量式的编码任务。每个任务都建立在前一个任务的基础上，确保代码逐步集成，没有孤立或未连接的代码。

## 任务列表

- [x] 1. 创建 Redis 键名管理器
  - 创建 `app/core/redis_keys.py` 文件
  - 实现 `RedisKeyPattern` 枚举定义验证码键名模式
  - 实现 `RedisKeyConfig` 类定义过期时间配置
  - 实现 `RedisKeyManager` 类提供键名生成方法
  - _需求: 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7_

- [ ]* 1.1 为 Redis 键名管理器编写单元测试

- [x] 2. 更新配置系统支持验证码配置

- [x] 3. 创建验证码 Schema 模型

  - _需求: 2.8, 2.10, 3.1_

- [x] 4. 实现验证码服务
  - 创建 `app/services/captcha_service.py` 文件
  - 实现 `CaptchaService.generate_captcha()` 方法
    - 从配置读取验证码参数
    - 创建 SpecCaptcha 实例
    - 生成验证码文本并转小写
    - 生成 UUID 作为 captcha_key
    - 存储到 Redis 并设置过期时间
    - 生成 Base64 图片
    - 添加日志记录
  - 实现 `CaptchaService.verify_captcha()` 方法
    - 从 Redis 获取存储的验证码
    - 比较验证码（不区分大小写）
    - 验证成功后删除验证码
    - 验证失败保留验证码
    - 添加日志记录
  - _需求: 2.1, 2.2, 2.3, 2.4, 2.5, 2.6, 2.7, 2.9, 3.2, 3.3, 3.4, 3.5, 3.6, 3.7, 3.8, 5.1, 5.2, 5.3, 5.4, 5.5_
